One line that reads as a hilarious autocorrect fail: a text to the boss where
"meeting" slips into "mating". Ten candidate slips were scored against the
house judge's brief — funny on first read, a clear and surprising wrong word,
reads as a real autocorrect slip, clear without explanation, specific rather
than generic — and the strongest won.

## Run it

```sh
python3 main.py
```

Writes the single winning line (53 characters, one line, nothing else) to
`/output/entry.txt`. Pure Python standard library, no third-party packages.
